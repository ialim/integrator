### Aggregate views

**Architecture delta**
- **Boundaries:** Staff → Shared and Staff → Notifications go only through public `Actions` and `Queries` (`SendStaffInvitation.php:5-6`, `ListStaff.php:5`). Shared imports no other module. No model crosses a module.
- **Capability check:** the kernel → Staff capability link is inverted through the `Shared\Capabilities\CapabilityCheck` interface.
- **Disposition:** clean, accept.
- **Open seam:** other modules have no public way to declare capabilities yet. This is recorded in the spec-1-5 notes, and Epic 2 is the first to need one. It is folded into action item A6.

**Duplication map**
- **Accessibility test helpers:** `expectNoViolations`/`expectNoSidewaysScroll` are copied between `console.spec.ts:31-62` and `app.spec.ts:29-45`, and the copies have already drifted. The console copy has the animation wait from `7e5c269`; the app copy does not. **Fix now** (small): one shared helper module.
- **"Sessions revoked" audit row:** built inline three times (`DeactivateStaffAccount.php:57`, `ResendInvitation.php:53`, `ResetSignIn.php:50`). Accept; candidate for `RevokeStaffSessions` to write it.
- **Refusal wording:** hard-coded "Ask an Admin" strings sit beside the registry's wording (`StaffAccountAction.php:45`, `InvitationUnusable.php:14`, `SignOutInactiveStaff`). Accept for now.
- **Time formatting:** moved to `Shared/Formats` in 1.7, with name leftovers (`formatWat`, `nowWat`, `ends_at_wat`). Accept; this is cosmetic.

**Size growth**
- **Candidates by net churn:**
  - `theme.css` (776 lines, 76 `.fi-` overrides, 18 `!important`)
  - `StaffAccountsFlowTest.php` (642)
  - `console.spec.ts` (489)
  - `session.ts` (459)
  - `ListStaff.php` (413 lines, 34 methods)
- **Assessment:** `ListStaff` holds every staff-account dialog, the error mapping and a cross-module read (`invitationsInDoubt`, `:367-389`). It is the one to watch. Defer splitting it until Epic 4 adds deputies to the same page.
- **Filament upgrades:** `theme.css` and the copied `group.blade.php` (252 lines) are an upgrade risk with every Filament release. Accept, with a checklist (action item A6).

**Pattern divergence**
- **`strict_types`:** only `Format.php` and `InvalidFormatInput.php` declare it (2 of 165 files).
- **Clock:** fetched with `app(Clock::class)` in five production files, against constructor injection elsewhere: `StaffAccountAction.php:86`, `ConsoleShell.php:29`, `RefusalWords.php:75`, `StaffMember.php:97`, `ApiResponse.php:46`.
- **`final`:** three concrete classes are not final (`InvitationLinks`, `AuditChain`, `AppServiceProvider`). `AuditChain` lost `final` for a test mock.
- **Disposition:** accept for now. Pick one convention for each (folded into action item A6) before Epic 2 copies whichever it sees first.

- **Merge order (A4):** merge the stacked branches one by one, or merge `story-1-7-app-shell`, which holds all seven? The answer decides whether `main` keeps one commit per story.
